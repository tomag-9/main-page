# Návrhy slovenských textov

Návrhy označené „ok“ sú zapracované do stránky vrátane schválenej pätičky a upraveného kontaktného textu. Pri položkách „nope“ zostalo pôvodné znenie. Tabuľka zachováva pôvodné texty, návrhy a tvoje rozhodnutia ako záznam zmien. Texty v sekcii Prístup a zápis názvu `zdravy-projekt` boli upravené samostatne.

Odporúčaný tón: prirodzená slovenčina, konkrétne formulácie a prvá osoba. Technické výrazy ako API, CI/CD či PWA majú v popisoch projektov svoje miesto; doslovné preklady anglických sloganov sa dajú nahradiť jednoduchšími vetami.
